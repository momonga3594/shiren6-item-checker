# 天津神・国津神キャラ プロンプトキット（GPT Image 用）

プロンプトを **【共通スタイル】＋【キャラ固定要素】＋【シーン指定】** の3部品で組み立てます。
画風を変えたいときは共通スタイルだけ、キャラを差し替えたいときは固定要素だけ、絵の内容を変えたいときはシーンだけを書き換えれば済みます。

## 使い方

1. 下の「共通スタイル」をコピーする
2. 描きたいキャラの「固定要素」を続けて貼る
3. 「シーン指定」から1つ選んで最後に貼る
4. **最初の1枚は必ず「シーンA：デザインシート」** で作る。できた画像を以降のチャットに添付し、シーン指定の冒頭に「添付画像のキャラクターデザインを維持して」と付けると、デザインがぶれにくくなる

> 重要な特徴ほど前に書いてあります。GPTが細部を落としたときは、落ちた要素をシーン指定の末尾に「〇〇を必ず描いて」と1行足すと直りやすいです。

```
【共通スタイル】

```

## 2. キャラ固定要素（10キャラ・髪色修正版）

### 髪色・シルエットの見分け表

前回案から、黒髪が重なっていた **タケミカヅチ（→金髪）** と、赤系が重なっていた **サルタヒコ（→白髪に赤メッシュ）** を変更しました。

| キャラ | 髪色 | 一目で分かるシルエットの特徴 |
|---|---|---|
| アマテラス | 黒→金グラデのロング | 背中の機械の光輪、床近くまである白コート |
| ツクヨミ | 青みの銀、片側だけ長いボブ | 三日月バイザー、二本の三日月刀 |
| タケミカヅチ | **明るい金髪の外ハネショート**（内側は黒） | 突き立てた大剣の上に座る、片側だけの肩鎧 |
| アメノウズメ | ネオンピンク→オレンジのツインテール | 長いツインテールとたなびく羽衣、マイクスタンド |
| オオクニヌシ | 栗色、ウサギ耳のようなループ結び | 背中の巨大バッグ、肩のウサギロボ |
| スクナビコナ | 黄緑のショート | 小柄、浮遊ポッド、蛾の羽のフード |
| タケミナカタ | 赤髪の太い三つ編み | 両腕の巨大な手甲、筋肉質 |
| コノハナサクヤ | 淡い桜色（白に近い）のウェーブ | 花束とエプロン |
| イワナガ | 黒（マスクからこぼれる程度） | 全身重装甲、巨大な岩の盾 |
| サルタヒコ | **白髪のウルフカットに赤メッシュ** | 赤い天狗風ハーフマスク、長いマフラー、バイク |
| スサノオ | 黒にティールのメッシュ、ボサボサ | 螺旋状に伸びる蛇腹剣、破れたジャケット |

> ウズメとサクヤはどちらもピンク系ですが、ウズメは**濃いネオンカラー**、サクヤは**白っぽい淡色**にして、色の濃さで区別しています。

## 3. シーン指定（差し替え用）

### A：デザインシート（最初の1枚はこれ）
```
【シーン指定】
白背景のキャラクターデザインシートとして描いてください。同じキャラクターの全身を、正面・背面・斜め45度の3体並べ、右側に武器や持ち物の単体の設定画と、表情差分の顔アップを3つ（通常・笑顔・怒り）配置してください。ポーズはまっすぐ立った自然な立ちポーズ、影はごく控えめに。横長3:2の構図。
```

### B：ガチャ演出風のメインビジュアル
```
【シーン指定】
添付画像のキャラクターデザインを維持してください。キャラクターの個性が一番伝わる、ダイナミックでかっこいい全身の決めポーズ。服や髪が風で大きくなびき、武器や能力のエフェクトを派手に描いてください。背景はキャラのイメージカラーを使ったグラフィカルな背景（幾何学模様、ハーフトーン、斜めのライン、光のエフェクト）。縦長2:3の構図。
```

### C：戦闘シーン
```
【シーン指定】
添付画像のキャラクターデザインを維持してください。夜のネオン街の路上で、異形の敵（黒い霧でできた怪物）と戦っている瞬間を、斜め下から見上げるアングルで描いてください。攻撃を放つ瞬間の躍動感、動きのブレ、飛び散る火花や破片のエフェクト。縦長2:3の構図。
```

### D：日常のオフショット
```
【シーン指定】
添付画像のキャラクターデザインを維持してください。戦闘のない休日の一コマとして、下町のカフェのテラス席でくつろいでいる様子を描いてください。武器は持たず、服装は固定要素の雰囲気を残したままカジュアルに着崩す。柔らかい午後の自然光、リラックスした自然な表情。縦長2:3の構図。
```

### E：2人のツーショット
```
【シーン指定】
1枚目と2枚目の添付画像のキャラクターデザインを、それぞれ維持してください。2人の関係性（ライバル／相棒／姉妹など）が伝わるように、背中合わせ、または向かい合って並ぶ構図で全身を描いてください。左右で2人のイメージカラーを分けたグラフィカルな背景。縦長2:3の構図。
```

> 2人とも「固定要素」をプロンプトに入れると、特徴が混ざりやすくなります。ツーショットは添付画像で特徴を伝え、文章は関係性と構図だけにするのがおすすめです。
