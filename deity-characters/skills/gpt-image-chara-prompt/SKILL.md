# GPT Image 用キャラクタープロンプト作成

ChatGPT（GPT Image）は、自然な文章で丁寧に説明するほど指示をよく守る。一方で次の弱点がある。
- 長すぎる指示は、後半の要素が落ちやすい
- 生成するたびにデザインが少しずつ変わる
- 既存の作品名や作家名で画風を指定すると、断られたり効かなかったりする

このスキルは、これらの弱点を **3部品構成** と **2段階の生成手順** で補う。

## 3部品の役割

| 部品 | 中身 | 変える頻度 |
|---|---|---|
| 【共通スタイル】 | 画風、線、塗り、頭身、「文字を入れない」などのルール | ほぼ固定（作品全体で1つ） |
| 【キャラ固定要素】 | そのキャラが毎回必ず同じであるべき見た目 | キャラごとに1つ |
| 【シーン指定】 | ポーズ、構図、背景、表情、縦横比 | 毎回差し替える |

部品を分けておけば、ユーザーは画風・キャラ・シーンのどれかだけを差し替えられる。毎回すべてを書き直す必要がなくなり、修正箇所も1か所で済む。

## 手順

### 1. 設定を集める
会話の中のデザイン案、ユーザーが渡した文章、箇条書きから設定を拾う。足りない部分は、キャラのコンセプトに合う具体的な内容をこちらで補い、補ったことを短く伝える。質問を重ねるより、まず叩き台を出してユーザーに直してもらうほうが早い。
ただし、画風の方向性がまったく分からないときだけは一言確認する（例：ソシャゲ調、日本のTVアニメ調、厚塗りなど）。

### 2. 共通スタイルを書く
`references/style-presets.md` から近いプリセットを選び、ユーザーの要望に合わせて調整する。
- **作品名・ゲーム名・作家名は書かない。** 「〇〇風」と言われたら、その画風の特徴（線の太さ、塗り方、配色、ファッションの傾向、等身）を言葉で説明する。こうすると規約上の断りを避けられ、画風もよりはっきり伝わる。
- 「画像内に文字・ロゴを入れない」「既存作品ではないオリジナルデザイン」を必ず入れる。GPT Image は勝手に文字を書き込むことが多いため。

### 3. キャラ固定要素を書く
以下の順に箇条書きで書く。GPTは前に書かれた内容ほど守るので、見分けるのに大事な特徴から並べる。
1. 1行目：モチーフ・立場・年代・体型（「〜をモチーフにした、〜の女性」）
2. **最重要**：そのキャラを一目で識別できるシルエットの特徴を1〜2個
3. 髪（色、長さ、髪型）
4. 顔（瞳の色、表情の傾向、ほくろや傷などの印）
5. 服（上から下へ、素材と色）
6. 武器・持ち物・相棒
7. 配色（基調3色＋アクセント1色）

**ポーズと背景は固定要素に入れない。** シーンを変えたときに矛盾するため。
1キャラの固定要素は、おおむね400〜600字に収める。それより長いと細部が落ちやすい。

### 4. シーン指定を書く
`references/scene-presets.md` から選ぶか、ユーザーの要望に合わせて新しく書く。
- 新しいキャラの最初の1枚は **デザインシート（正面・背面・斜め、武器、表情差分）** を勧める。できた画像を次の生成に添付すると、文章よりも確実に見た目を固定できるため。
- 2枚目以降のシーン指定は、冒頭を「添付画像のキャラクターデザインを維持してください。」で始める。
- 縦横比を明記する（立ち絵は2:3、デザインシートや横長の場面は3:2、アイコンは1:1）。

### 5. 複数キャラを作るときの確認
3キャラ以上をまとめて作るときは、出力の前に髪色・メインカラー・シルエットが重なっていないか確認する。重なっていたら、どれを変えるかを提案する。
ソシャゲのキャラは、小さなアイコンや遠目のシルエットでも誰か分かる必要があるため。結果は「髪色／一目で分かる特徴」の短い表で示す。

## 出力形式

ユーザーがコピーして貼るだけで使えるように、次の形で出す。

````
## 共通スタイル
```
【共通スタイル】
（本文）
```

## キャラ固定要素：〈キャラ名〉
```
【キャラ固定要素】
（本文）
```
（キャラの数だけ繰り返す）

## シーン指定
```
【シーン指定】
（本文）
```

## 組み立て済みプロンプト（そのまま貼れる完成形）
```
【共通スタイル】…
【キャラ固定要素】…
【シーン指定】…
```
````

- 組み立て済みプロンプトは、キャラ1人につき1本付ける。キャラが多い場合は、最初の1キャラ分だけ付け、残りは「部品を同じ順に並べれば完成形になる」と添える。
- 最後に、使い方のコツを3行以内で付ける：最初はデザインシートで作る、できた画像を添付して見た目を維持する、落ちた要素は末尾に「〇〇を必ず描いて」と足す。
- ユーザーがファイル保存を求めたら、同じ内容をMarkdownファイルに書き出す。

## 表現上の注意
- 実在の神仏や宗教がモチーフの場合、神具を武器にする表現や露出の多い表現は、公開範囲によって控えめにするよう一言添えるとよい。
- 小柄なキャラや童顔のキャラは「小柄な成人女性」のように年齢を明記し、子どもに見える描写と性的な描写を組み合わせない。
- 実在の人物に似せたキャラ、既存作品のキャラの再現は作らない。オリジナルのデザインに置き換えて提案する。
