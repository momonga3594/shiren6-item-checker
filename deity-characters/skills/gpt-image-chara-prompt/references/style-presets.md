# 共通スタイルのプリセット

ユーザーの要望に一番近いものを選び、必要に応じて語句を足し引きする。どのプリセットにも、最後の2文（文字を入れない／オリジナルデザイン）は必ず残す。

## 1. 中国系ソシャゲ調（都会・ストリート）
近年の中国系アニメ調アクションゲームの公式キャラクターイラストのような画風で、オリジナルキャラクターを描いてください。都会的でスタイリッシュな、ストリートファッションとテックウェアを融合したデザインです。くっきりした太めの線画、セル塗りをベースに柔らかいグラデーションと強いハイライト、彩度の高いアクセントカラー、グラフィカルで大胆な色面構成。顔はアニメ調で目が大きく、等身は7〜7.5頭身のすらりとしたプロポーション。画像内に文字・ロゴ・サインは入れないでください。既存作品のキャラクターではないオリジナルデザインです。

## 2. 中国系ソシャゲ調（ファンタジー・幻想）
近年の中国系オープンワールドRPGの公式キャラクターイラストのような画風で、オリジナルキャラクターを描いてください。装飾の多い幻想的なファンタジー衣装、金属や宝石の細かいパーツ、透け感のある布。繊細な細い線画、柔らかいアニメ塗りに淡い光のグラデーション、ハイライトにきらめきの粒子。顔はアニメ調で目が大きく、等身は7頭身前後。画像内に文字・ロゴ・サインは入れないでください。既存作品のキャラクターではないオリジナルデザインです。

## 3. 日本のTVアニメ調
日本のTVアニメの公式設定画・キービジュアルのような画風で、オリジナルキャラクターを描いてください。均一な太さのすっきりした線画、影は1〜2段階のはっきりしたアニメ塗り、落ち着いた彩度。顔はアニメ調で、等身は6.5〜7頭身。画像内に文字・ロゴ・サインは入れないでください。既存作品のキャラクターではないオリジナルデザインです。

## 4. 厚塗りイラスト調
厚塗りのデジタルイラストの画風で、オリジナルキャラクターを描いてください。線画は控えめにして、色と光の面で形を作る。ドラマチックな逆光とリムライト、質感がはっきり分かる素材の描き込み、映画的な色調。顔はアニメ寄りの半リアル、等身は7.5〜8頭身。画像内に文字・ロゴ・サインは入れないでください。既存作品のキャラクターではないオリジナルデザインです。

## 5. ちびキャラ・SD調
2.5頭身のデフォルメされたちびキャラの画風で、オリジナルキャラクターを描いてください。丸みのある太い線画、シンプルなセル塗り、明るくポップな配色、大きな頭と短い手足。グッズやスタンプに使えるような、まとまりのいいシルエット。画像内に文字・ロゴ・サインは入れないでください。既存作品のキャラクターではないオリジナルデザインです。
