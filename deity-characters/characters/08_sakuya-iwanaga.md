# ⑧ 木花咲耶（コノハナサクヤ）・磐長（イワナガ）姉妹

> 花屋の看板娘（炎属性・アタッカー）と、その姉（防御担当） ／ 国津神 ／ 姉妹で編成するとボーナスが付く

## 使い方
1. **①-A** と **①-B** で、1人ずつデザインシートを作る（2人を最初から一緒に描くと、特徴が混ざりやすい）
2. できた2枚の画像を添付して、**② ツーショット** のプロンプトを貼る
3. 生成された絵で抜け落ちた要素があれば、プロンプトの末尾に「〇〇を必ず描いて」と1行足して再生成する

1人ずつのメインビジュアルを作りたい場合は、`../prompt-kit.md` の「シーンB」を差し替えて使ってください。

## ①-A デザインシート：木花咲耶
```
【共通スタイル】
近年の中国系アニメ調アクションゲームの公式キャラクターイラストのような画風で、オリジナルキャラクターを描いてください。都会的でスタイリッシュな、ストリートファッションとテックウェアを融合したデザインです。くっきりした太めの線画、セル塗りをベースに柔らかいグラデーションと強いハイライト、彩度の高いアクセントカラー、グラフィカルで大胆な色面構成。顔はアニメ調で目が大きく、等身は7〜7.5頭身のすらりとしたプロポーション。画像内に文字・ロゴ・サインは入れないでください。既存作品のキャラクターではないオリジナルデザインです。

【キャラ固定要素】
日本神話の桜と火の女神・木花咲耶姫をモチーフにした、花屋の看板娘の女性。
・最重要：手のひらの上で桜の花びらが燃えて炎に変わっていく演出と、片腕に抱えた花束
・髪：白に近い淡い桜色のゆるいウェーブのロングヘア、桜の花の髪飾り
・顔：柔らかい微笑み。ただし瞳の奥に炎のような赤い光が揺らめいている
・服：体にフィットした白いニットのワンピースの上に、深緑の花屋のエプロン（ポケットに花鋏）、ストラップ付きのローヒールのパンプス
・配色：淡い桜色・白・深緑、アクセントに炎のオレンジ

【シーン指定】
白背景のキャラクターデザインシートとして描いてください。同じキャラクターの全身を、正面・背面・斜め45度の3体並べ、右側に武器や持ち物の単体の設定画と、表情差分の顔アップを3つ（通常・笑顔・怒り）配置してください。ポーズはまっすぐ立った自然な立ちポーズ、影はごく控えめに。横長3:2の構図。
```

## ①-B デザインシート：磐長

日本神話の岩の女神・磐長姫をモチーフにした、木花咲耶の姉で、長身の女性。
・最重要：全身を覆う灰色と黒の重装甲アーマー（岩石のようなゴツゴツした質感のプレート、ところどころに苔と琥珀色の鉱石の結晶）と、片手に持つ巨大な岩の盾
・顔：フルフェイスのマスクで完全に隠れ、目のスリットから琥珀色の光が漏れている
・髪：マスクの縁から艶のある長い黒髪がこぼれ落ちている
・雰囲気：重厚で動かない、守護者らしい佇まい

## ② ツーショット（①-A・①-Bの画像を2枚添付して使う）
```
【共通スタイル】
近年の中国系アニメ調アクションゲームの公式キャラクターイラストのような画風で、オリジナルキャラクターを描いてください。都会的でスタイリッシュな、ストリートファッションとテックウェアを融合したデザインです。くっきりした太めの線画、セル塗りをベースに柔らかいグラデーションと強いハイライト、彩度の高いアクセントカラー、グラフィカルで大胆な色面構成。顔はアニメ調で目が大きく、等身は7〜7.5頭身のすらりとしたプロポーション。画像内に文字・ロゴ・サインは入れないでください。既存作品のキャラクターではないオリジナルデザインです。

【シーン指定】
1枚目と2枚目の添付画像のキャラクターデザインを、それぞれ維持してください。1枚目は淡い桜色の髪の花屋の女性（木花咲耶）、2枚目は全身を岩のような重装甲で覆った長身の女性（磐長）です。姉の磐長が巨大な岩の盾を構えて妹の背後に守るように立ち、妹の木花咲耶が前で花束を抱えてこちらを振り返る構図で、2人とも全身を描いてください。妹の手のひらでは桜の花びらが燃えて炎に変わっている。背景は遠くに富士山のシルエット、舞い散る桜吹雪と火の粉。妹は桜色・白・深緑、姉は灰・黒・琥珀の対照的な配色。縦長2:3の構図。
```
