# 動作確認

## 自動テスト

Node.js 22以上で、リポジトリのディレクトリから実行します。

```sh
node --test --test-isolation=none tests/shiren6.test.cjs
```

`index.html` 内の実際のスクリプトを簡易DOMと保存領域で実行します。計算、印の加算・乗算、価格条件、名前検索、保存復元、ボヨヨンの推奨・取り消しを検証します。削除した未識別のみ表示・呼び名・メモ欄が復活しないことと、以前保存されたメモを変更しないことも確認します。ブラウザのレイアウトや実ゲームの計算精度を保証するものではありません。

## 実画面の確認項目

- ボヨヨン：部屋の内部と外周を編集し、サイズ変更後も内部の壁が残ること、取り消しで前の形へ戻れること。
- 「おすすめ位置を選ぶ」で位置・方向・軌道が一致すること。「足元回収のみ」で該当する候補だけになること。
- 位置と方向の一覧が折りたためること。行・列番号が案内文と一致すること。
- ダメージ：直接入力を有効にすると武器／盾の選択と強化値が無効になること。選択した印と追加倍率を二重入力していないこと。
- 識別：未識別のみ表示・呼び名・メモ欄がなく、正式な名前の検索と識別状態の切り替えは使えること。
- 同じブラウザ・同じURLで再読み込みし、計算条件と部屋・位置・方向が復元されること。
- 買値／売値、通常／呪い／祝福／通常＋祝福の組み合わせで候補と価格表示が一致すること。「通常＋祝福」は呪い価格を含まないこと。祝福の対象外カテゴリでは「祝福」で案内が出て、「通常＋祝福」では通常価格が使われること。
- 「通常＋祝福」で買値100Gを選ぶと、暴走の種・毒草は祝福一致の水色枠、くねくね草・高飛び草は通常一致の黄色枠になること。一致した状態を示す文字も表示されること。
- 価格を複数選び同じ道具の通常・祝福が両方一致した場合は、二色枠と「通常・祝福価格で一致」が出ること。価格フィルター解除後は一致の枠と文字が消えること。
- 「通常＋祝福」の価格検索では、通常価格に一致する道具（両方一致を含む）が先、祝福価格だけに一致する道具が後に並ぶこと。同じグループ内の識別状態による順序は維持すること。
- 375px程度の狭い画面で方向ボタンを操作でき、最大サイズのグリッドだけが横スクロールできること。

保存はブラウザのローカルストレージを使用します。別端末、別URLのプレビュー、シークレットウィンドウには引き継がれません。編集の取り消し履歴は現在のページを開いている間だけ保持します。
